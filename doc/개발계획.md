# MinsPDFViewer 개발 계획 및 기능 현황

## 1. 프로젝트 개요
`MinsPDFViewer`는 WPF 기반의 경량·고성능 PDF 뷰어 및 편집기입니다.
PdfiumViewer / pdfium.dll을 통한 렌더링 및 텍스트 처리, BouncyCastle 기반 디지털 서명(RFC 3161 타임스탬프, LTV, 그래픽 도장 서명), Windows Media OCR을 결합하여 문서를 평탄화(Flattening)하지 않고 원본 구조를 유지하며 주석(Annotation) 및 Searchable PDF를 생성·관리하는 것을 목표로 합니다.

---

## 2. 지금까지 반영되어 있는 기능 목록 (완료 현황)

### 2.1 PDF 뷰어 코어
- [x] **Pdfium 렌더링 엔진**: 고속 PDF 페이지 렌더링, 페이지 가변 줌/스크롤, 연속 스크롤 뷰
- [x] **선명한 텍스트 렌더링 (ClearType/LCD Text)**:
  - 디스플레이 DPI(100%, 125%, 150%)와 `req.Zoom`에 맞춘 1:1 물리 픽셀 매칭 렌더링 (다운스케일링 뭉개짐 및 블러 완전 제거)
  - PDFium `PdfRenderFlags.Annotations | PdfRenderFlags.LcdText | PdfRenderFlags.CorrectFromDpi` 플래그 적용 (RGB 서브픽셀 텍스트 안티앨리어싱)
  - WPF `<Image>` 컨트롤 `RenderOptions.BitmapScalingMode="HighQuality"`, `RenderOptions.ClearTypeHint="Enabled"`, `SnapsToDevicePixels="True"`, `UseLayoutRounding="True"` 적용
- [x] **썸네일 사이드바**: 좌측 페이지별 썸네일 표시 및 페이지 이동 네비게이션
- [x] **북마크(목차) 트리**: 계층형 북마크 로드 및 페이지 점프, 추가/삭제/이름수정/들여쓰기(Indent/Outdent)
- [x] **단일/선택 페이지 회전**: 좌측 썸네일에서 선택한 페이지 또는 현재 활성 페이지만 단독 회전(90도/270도 및 누적 회전각 저장 지원)
- [x] **페이지 조작**: 페이지 순서 변경(Drag & Drop), 페이지 삭제, 빈 페이지 삽입

### 2.2 암호화 PDF 지원
- [x] **비밀번호 보호 PDF 열기**: 암호화된 PDF 파일 감지 시 비밀번호 입력 다이얼로그(`PasswordDialog`) 표시
- [x] **비밀번호 재시도 및 취소 처리**: 비밀번호 불일치 시 안내 및 재입력 유도, 유효한 암호로 문서 및 텍스트 레이어 로드

### 2.3 주석(Annotation) 기능
- [x] **하이라이트 / 밑줄**: 마우스 드래그 텍스트 선택 기반 주석 추가, 색상 변경
- [x] **텍스트 상자(FreeText)**: 캔버스 기반 텍스트 상자 생성, 이동, 크기 조절, 글꼴/색상/크기 변경
- [x] **비평탄화(Non-flattened) 저장**: PDF 표준 사양 준수(Appearance Stream, /DA, /DR 리소스 딕셔너리 관리)
- [x] **PDFium/Foxit 호환성**: 외부 뷰어(Foxit, Adobe, Chrome 등)에서도 주석이 정상 표시되도록 호환성 패치 적용

### 2.4 전자서명 및 검증
- [x] **BouncyCastle 기반 서명**: PFX/P12 인증서 및 Windows 인증서 저장소 연동
- [x] **시각적 도장(Visual Stamp)**: 서명 위치 마우스 드래그 지정, 서명 이미지 스탬프 합성
- [x] **증분 저장(Incremental Update)**: 기존 서명 파기를 방지하는 ByteRange 기반 증분 서명
- [x] **서명 검증**: 무결성 검증, 인증서 체인 유효성 및 만료 여부 확인

### 2.5 OCR 및 Searchable PDF 엔진 (pdf-parser 초경량 방식)
- [x] **Windows Media OCR**: 한국어/영어 언어 팩 지원, 이미지 기반 PDF의 텍스트 및 Bounding Box 인식
- [x] **초경량 Glyphless Text Layer (`PdfGlyphlessOcrService`)**:
  - `build_glyphless_ttf`: 532바이트의 극소형 TrueType 빈 글리프 폰트 바이너리
  - `/Type0` + `/Identity-H` + `/CIDFontType2` + `/CIDToGIDMap` + `/ToUnicode` Identity CMap 구조 생성
  - Recursive XY-Cut 알고리즘(`RecursiveXyCut`): 2단 문서, 문단, 제목 간격을 인식하여 자연스러운 읽기 순서 정렬
  - `BT 3 Tr ... Tz ... <hex> Tj ET`: 투명 텍스트 렌더링, 단어 간 공백(" ") 첨부 및 가로 배율(`Tz`) 조정을 통해 단어 간격 및 검색 호환성 확보
  - 기존 수백 MB ~ 1GB 이상 파일 크기 폭증 문제 완전 해결 (수십 KB 수준 유지)
  - **좌표계 (2026-10-23)**: `OcrWordInfo.BoundingBox`는 줌과 무관한 PDF 포인트, PDFium이 원본 페이지를 그린 화면(앱 내 회전 전) 기준 왼쪽 위 원점. 저장 시 CropBox 오프셋·원본 `/Rotate`(저장본 `/Rotate` − 앱 회전)로 사용자 공간에 변환하고, 회전 페이지는 `Tm` 축을 돌려 화면에서 가로로 읽히게 넣음
  - **MobileScan과 같은 글꼴 규약**: Ascent 880 / Descent -120, 기준선 = 단어 아래 + 0.12em → 뷰어 선택 상자 = 단어 상자. ToUnicode `beginbfrange`는 블록당 100개 이하(100·100·56)
  - **글리프**: 632바이트 TTF(fontTools 생성), GID 1은 넓이 0인 대각선 윤곽(칠할 것 없음). 완전히 빈 글리프는 PDFium이 세로 방향(90°/270° 페이지) 글자를 텍스트로 인식하지 못함
  - **증분 기록 견고화**: 원본 내용을 `q … Q`로 감쌈(공유 q 스트림), `/Resources` 상속·간접 참조·중첩 사전·간접 `/Font` 처리(`PdfSyntax`), `/Contents`가 배열 객체를 가리켜도 처리, trailer에 `/Info` 유지, 다시 OCR하면 이전 층(`/MinsOcrLayer` 표식) 교체, 암호화 PDF는 건너뜀(로그)

### 2.6 검색(Search) 기능
- [x] **순차적 페이지 탐색**: 기존 루프 인덱스 누적 버그(0, 2, 5, 9... 삼각수 페이지 건너뛰기) 수정하여 모든 페이지를 누락 없이 1페이지씩 탐색
- [x] **문서 끝/시작 래핑(Wrap-around) 탐색**: 처음/끝 도달 시 재탐색 결과 정상 반영 및 해당 페이지 스크롤 이동
- [x] **메모리 내 OCR 단어 실시간 검색**: OCR 실행 직후 아직 파일로 저장하지 않은 상태에서도 `pageVM.OcrWords`를 통해 즉시 단어 및 다중 어절 검색/하이라이트 지원
- [x] **다중 일치 항목 시각화**: 페이지 내 모든 매치 항목을 노란색 하이라이트로 표시하고, 현재 선택된 포커스 단어는 주황색으로 강조 표시

### 2.7 텍스트 선명도 강화 및 로딩 성능 최적화
- [x] **광학적 Stem Darkening (감마 1.20 LUT)**:
  - Foxit/Adobe 수준의 선명한 글자 획 복원: 256-바이트 감마 룩업 테이블(LUT)을 통한 고속 unsafe 포인터 픽셀 변환
  - 안티에일리어싱으로 인해 흐려진 중간 회색 엣지 픽셀을 또렷한 블랙 코어로 보정하여 글자 획 가늘어짐 및 흐림 현상 해결
- [x] **밝기 언샤프 (2026-10-23)**: 감마 LUT 뒤에 밝기(Y)만 3×3 가우시안 언샤프(강도 `PdfService.SharpenAmount` = 0.6), ΔY를 RGB에 똑같이 더해 LCD 색번짐은 키우지 않음. 스캔 PDF(1비트 600dpi JBIG2)를 화면 크기로 줄일 때 퍼지는 획 가장자리를 세움 — `TestFiles/foxit.png`·`mins.png` 비교 근거
- [x] **2단계 렌더 정리 (2026-10-23)**: 빠른 패스는 고해상도의 0.5배(픽셀 1/4), LCD·후처리 없이, 이미 그림이 있으면 생략(줌 변경·저장 후 재렌더). 이전에는 두 패스가 같은 해상도라 같은 페이지를 두 번 그림
- [x] **초기 문서 로딩 및 이전 열람 위치 복원 최적화**:
  - `_historyService`의 이전 페이지 위치(`initialPageIndex`) 복원 시 해당 가시 영역 페이지 렌더링에 최고 우선순위 부여
  - 썸네일 백그라운드 렌더링 시 메인 뷰 렌더링 작업(`PdfService.HasPendingRenders`)에 양보(Yield) 및 `initialPageIndex` 중심 외향 순차 생성으로 락 경합(`PdfiumLock`) 완전 해소
  - `InitializeDocumentAsync`에서 `PdfiumLock` 획득 횟수를 페이지별 N회에서 1회로 축소하여 다중 페이지 로딩 지연 단축

## 4. 남은 이슈
- 검색 하이라이트: `FindTextRects`는 PDF 사용자 공간 좌표를 돌려주는데 `HighlightMatch`는 회전 없는 페이지로 가정 → 원본 `/Rotate`가 있거나 앱에서 돌린 페이지에서는 하이라이트 위치가 어긋남 (텍스트 층 자체는 정확)
- `PdfBookmarkRewriteService`·`PdfSignatureService`의 증분 trailer에 `/Info` 누락 → 북마크 저장·서명 후 문서 속성(제목 등)이 안 보일 수 있음
- Glyphless·북마크·서명 증분 기록기는 파일 전체를 Latin1 문자열로 읽음 → 1GB급 파일에서 메모리 2GB 이상
